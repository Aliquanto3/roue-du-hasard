# Roue du hasard v1.0.0

Première version publiée. Une roue qui désigne au hasard qui reçoit un cadeau, dans un seul fichier `roue.html` : aucune installation, aucun compte, aucun droit administrateur.

## Ce que fait l'application

- Participants : ajout, renommage, suppression, collage d'une liste d'un coup ; doublons permis avec avertissement ; 60 caractères au maximum par nom ; 2 noms au minimum pour lancer.
- Couleurs modifiables par nom, avec retour à la couleur par défaut ; texte toujours lisible.
- Cadeaux : liste facultative et ordonnée, attribuée tirage après tirage, avec récapitulatif et « Recommencer les attributions ».
- Lancement par le bouton, la touche Espace ou Entrée, ou un toucher sur la roue ; rotation de 4 à 6 secondes.
- Tirage équitable : secteurs de même taille, gagnant tiré avant l'animation avec le générateur aléatoire de sécurité du navigateur.
- Annonce en grand (nom, couleur, cadeau) avec « Relancer » et « Fermer ».
- Historique copiable et effaçable, « Annuler le dernier tirage », option « Retirer les gagnants de la roue ».
- Sauvegarde automatique dans le navigateur, export et import d'un fichier JSON pour passer une liste d'un appareil à l'autre.
- Rendu en relief ou plat, son généré dans le navigateur (coupable), confettis.
- Accessibilité : clavier, annonce aux lecteurs d'écran, animation remplacée par un fondu si le système demande moins de mouvement.
- Vie privée : aucune requête réseau une fois la page chargée, aucune statistique.

## Supports garantis

Windows avec Google Chrome. Les autres navigateurs, macOS, Linux et les téléphones sont prévus en V1.2 (`docs/v1.2-supports.md`) : ils peuvent fonctionner, mais ne sont pas garantis dans cette version.

## Limites connues

- Le mode projection (plein écran) n'est pas dans cette version : il est reporté en V1.2.
- Le fichier `roue.html` et la page GitHub Pages ne partagent pas leurs données : passez par l'export et l'import.
- Si le navigateur bloque le stockage (navigation privée, fichier local restreint), l'application fonctionne mais ne garde rien : pensez à exporter.
- Le chat à base de petit modèle de langage n'est pas inclus (prévu en V1.1).
