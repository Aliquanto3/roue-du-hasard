# V1.1 — Chat local pour piloter la roue (cadrage)

Demande d'Anaël du 2026-10-31. À traiter après la release `v1.0.0`, hors du run V1.

## Objectif

Un petit chat, servi par un petit modèle (SLM) sur le PC, qui exécute en langage courant les actions de l'application : ajouter ou retirer des personnes, afficher le cadeau prévu, basculer entre 2D et 3D, lancer la roue, couper le son, annuler le dernier tirage.

## Principes

- **Le modèle ne désigne jamais le gagnant.** Il demande l'action « lancer » ; le tirage reste fait par `crypto.getRandomValues` (F6).
- **Mêmes règles que l'interface.** Le chat appelle les actions de l'application, par des appels d'outils validés par un schéma, jamais une écriture directe dans l'état. Lancement interdit, liste verrouillée pendant la rotation : mêmes refus, mêmes messages.
- **Confirmation avant une action destructive** : vider la liste, effacer l'historique, retirer plusieurs personnes.
- **Le texte du modèle et les noms restent du texte** (N2), et un nom ne vaut jamais instruction : les noms sont des données, y compris un nom hostile importé.
- **Facultatif.** Sans modèle local, l'application V1 fonctionne à l'identique et le chat est simplement absent. Le fichier `roue.html` destiné aux novices ne doit rien exiger de plus.

## Préparation dès la V1

Une seule table d'actions (`src/actions.ts`, nom, paramètres, exécution, refus possible), utilisée par les boutons à partir de la story 2.2. Le chat s'y branchera sans reprise de l'interface. Rien d'autre n'est anticipé : ni code de chat, ni exception à la CSP.

## Décision à prendre avant le développement : où tourne le modèle

Le point dur est N1 : la CSP interdit toute connexion sortante et `file://` a une origine nulle.

| Option | Pour | Contre |
|---|---|---|
| **A. Ollama sur `localhost` (recommandée)** | Réutilise un outil courant, bon appel d'outils, `roue.html` reste léger | Installation requise ; exception CSP limitée à `localhost` ; autoriser l'origine de la page dans `OLLAMA_ORIGINS` |
| B. Modèle dans le navigateur (WebGPU) | Rien à installer | Dépendance et modèle hors du fichier de 200 Ko, téléchargement, N3 à revoir, inégal selon les machines |
| C. Petit serveur local dédié | Sert la page et le modèle sur la même origine, CSP simple | Un outil de plus à lancer, moins simple pour un novice |

Recommandation : une édition distincte `roue-chat.html`, avec l'exception CSP vers `localhost`, et un `roue.html` V1 inchangé, qui garde la promesse N1 sans réserve.
