# Story 6.2 — Bouton pour parler (V1.3)

Cadrage : `docs/v1.1-chat-slm.md` (section voix). Contrat du STT : `docs/specs/6.1-essai-stt.md` (whisper.cpp `whisper-server`, `large-v3-turbo` q5_0, port 5201, `npm run stt`). Code dans `src/chat/` seulement (contrat de 5.1) ; `roue.html` et `src/main.ts` inchangés.

## Critères d'acceptation
- C1. Client STT `src/chat/stt.ts` (tests `stt.test.ts`) : `creerClientStt({ url, delaiMs, fetch })`, défaut `/stt` (relais de C6), `delaiMs` 10 s. `transcrire(wav, { indices })` envoie le WAV au point d'accès constaté en 6.1 (multipart), avec les prénoms de la liste dans le champ d'indice (`prompt`) borné à 200 caractères, sans délimiteur interprétable. Le résultat est `{ texte, dureeMs }` ou un échec typé : `stt-absent` (connexion refusée), `delai`, `reponse-invalide`, `annule`. `fetch` est injectable.
- C2. Audio `src/chat/micro.ts` : `getUserMedia({audio:true})` puis `MediaRecorder` (webm/opus), conversion dans la page en WAV 16 kHz mono PCM 16 bits. Durée bornée à 15 s, pistes arrêtées à la fin. Aucune conservation après l'envoi : pas de stockage, pas de lien `blob:` gardé, pas d'envoi ailleurs qu'au STT.
- C3. Bouton « Parler » dans le panneau du chat (`panneau-chat.ts`), appui maintenu (pointeur, et Espace ou Entrée au clavier), `aria-pressed` pendant l'enregistrement, état visible (« J'écoute… », « Transcription… »). Textes dans `src/chat/textes.ts`. Absent si `navigator.mediaDevices` manque. Désactivé pendant la rotation comme la saisie.
- C4. Transcription affichée dans le champ « Commande » avant exécution, puis passée à la cascade par le même chemin qu'une commande tapée (`planifier`, confirmations comprises). L'utilisateur peut la corriger : un réglage « exécuter directement » est hors périmètre.
- C5. Refus propres, en texte seulement : micro refusé ou absent, STT absent (avec la commande `npm run stt`), délai, transcription vide. Le chat écrit continue de fonctionner.
- C6. Accès au STT par la même origine : `scripts/serveur-chat.mjs` relaie `POST /stt` (corps borné à 2 Mo, seulement `POST`, contrôle du Host existant) vers `http://127.0.0.1:5201/inference`. Toutes les autres routes de `whisper-server` restent inaccessibles depuis la page. Le client vise `/stt` par défaut ; `connect-src 'self'` suffit si la CSP l'autorise déjà, sinon il est ajouté, mais jamais le port 5201 en direct. `roue.html` garde sa CSP stricte (`check:size`). Taille de `roue-chat.html` mesurée, inférieure à 200 Ko.
- C7. Inspection (5.7) : la transcription brute et la latence du STT sont ajoutées à l'entrée de la commande.

## Tests
- Unitaires : client STT (succès, `stt-absent`, délai, réponse invalide, indices bornés et neutralisés), conversion WAV (en-tête, 16 kHz, mono).
- E2E (`tests/e2e/chat-voix.spec.ts`) : STT simulé par `page.route` sur `/stt`, et test unitaire ou d'intégration du relais (`serveur-chat.mjs` : Host refusé, méthode refusée, corps trop gros, STT absent → 502), faux micro (`--use-fake-device-for-media-stream`, `--use-fake-ui-for-media-stream`, Chromium seulement, test ignoré sur les autres moteurs avec raison) : appui, transcription affichée puis exécutée ; refus propre sans micro (permission refusée) et sans STT. Les fichiers E2E partagés touchés sont `chat-panneau.spec.ts` (ordre de tabulation, si le bouton s'y ajoute) et `edition-chat.spec.ts` (CSP).

## Hors périmètre
- Prénoms à l'oral (rapprochement phonétique, score) : 6.3. Essai en salle : 6.4.

## Réalisation
- Code : `src/chat/stt.ts` (client, indice borné à 200 caractères, nettoyage), `micro.ts` (capture, WAV 16 kHz mono 16 bits, 15 s), `voix.ts` (enchaînement sans DOM), bouton dans `panneau-chat.ts`, textes dans `textes.ts`. `main-chat.ts` ne propose le bouton que si `getUserMedia` et `MediaRecorder` existent.
- Relais : `scripts/relais-stt.mjs`, branché par `scripts/serveur-chat.mjs` (Host déjà contrôlé en amont). `POST` seulement (405), `Origin` étrangère refusée (403), corps `multipart/form-data` exigé (415), 2 Mo au plus (413), STT absent ou délai de 30 s : 502. Vers `127.0.0.1:5201/inference` uniquement ; `/load` et le reste restent fermés. Variables `ROUE_CHAT_PORT`, `ROUE_STT_PORT`, `ROUE_CHAT_FICHIER` : pour les tests seulement.
- CSP du chat : `connect-src 'self'` ajouté (jamais le port 5201) ; `check-size` aligné. `roue.html` inchangé.
- La transcription est placée dans « Commande » ; l'envoi (Entrée) suit le chemin d'une commande tapée. Un bouton désactivé suit la saisie (désactivée pendant la réflexion du chat) ; pendant la rotation, la roue refuse la commande comme pour une commande tapée.
- Inspection (C7) : champ facultatif `transcription` (`brut`, `latenceMs`) dans l'entrée, validé au chargement du stockage, affiché dans le détail.
- Tests : unitaires (`stt`, `micro`, `voix`, `controleur`, `inspection`), relais réel sur ports libres (`scripts/relais-stt.test.ts`, faux whisper-server), E2E `chat-voix.spec.ts` (Chromium, faux micro) et `edition-chat.spec.ts` (CSP, `/stt`).
