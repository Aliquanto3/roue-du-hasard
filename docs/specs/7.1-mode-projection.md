# Story 7.1 — Mode projection (F18)

Références : F18 (`docs/spec.md`), « Mode projection » de `docs/v1.2-supports.md`, corpus `docs/v1.1/corpus-commandes.jsonl` (`dir-16`, `dir-19`, `ind-11`, `ora-14`, `dir-24`).

## Critères d'acceptation
- C1. Action `modeProjection({ actif: boolean })` dans `actions.ts`, de la forme du corpus (pas de bascule) ; une valeur non booléenne vaut « sortir ». Sans refus possible, permise pendant une rotation (`SANS_VERROU`), sans effet dans l'essai à blanc (`essayer`) et sans `ControleProjection` (tests). L'état du domaine n'est pas touché.
- C2. `src/ui/projection.ts` : bouton « Mode projection » toujours visible (colonne de la roue), `aria-pressed`, libellé constant ; statut lu par une région `role=status` propre (l'annonce `aria-live` est inchangée). En projection, la page est fixée sur toute la fenêtre (`projection.css`) ; panneau (liste, cadeaux, historique, données, chat), réglages et récapitulatif des cadeaux sont masqués ; le titre reste pour les lecteurs d'écran ; le bouton passe, discret, en haut à droite.
- C2 bis. Bouton compact (icône dessinée en CSS, `aria-label` « Mode projection »), hors du flux en haut à droite de `.page__roue` : il n'ajoute aucune hauteur sous la roue, quelles que soient les polices (cas de polices larges à 568×480 et 320×568 dans `projection.spec.ts`), que la mesure `--roue-libre` / `--tiroir-max` (7.2) compte au pixel à 568×480 tiroir ouvert. Ordre de tabulation : lancer, relief, son, projection, champ d'ajout (`panneau.spec.ts` réaligné).
- C3. Plein écran : `requestFullscreen` sur `<html>` (l'annonce et les confettis restent visibles). La classe est posée tout de suite (`data-projection="fenetre"`) ; si la demande aboutit, `data-projection="plein-ecran"`. API absente (iPhone) ou refusée (pas de geste récent, commande du chat) : le repli pleine fenêtre CSS reste. Keyboard Lock (`navigator.keyboard.lock(['Escape'])`) quand il existe, pour que la page reçoive Échap en plein écran.
- C4. Sortie : bouton, Échap, `fullscreenchange` quand le navigateur sort seul. Ordre d'Échap avec Keyboard Lock (Chromium) : l'écouteur de la projection est posé au démarrage, avant celui de l'annonce (posé à l'ouverture) ; il voit l'annonce ouverte et la laisse se fermer ; le second Échap sort. Sans Keyboard Lock (Firefox, Safari), le navigateur garde Échap et sort du plein écran : si l'annonce est ouverte, `fullscreenchange` la ferme et la projection continue en pleine fenêtre (`data-projection="fenetre"`), un second Échap ou le bouton fait sortir ; sans annonce, il fait sortir du mode. Le plein écran n'est noté `plein-ecran` que si `document.fullscreenElement` est bien `<html>` après la promesse. Écouteurs du document posés une seule fois (`poserUneFois`).
- C4 bis. Le tiroir ouvert du chat (écran étroit, `#app:has(.chat[data-ouvert='true']) .page`, spécificité 1,3,0) ne réserve plus sa hauteur en projection : `projection.css` le neutralise par `html.projection #app .page.page--projection` (1,3,1), sans toucher à `panneau-chat.css`.
- C5. Focus : le bouton garde le focus à l'entrée ; si l'élément actif devient masqué (saisie du chat), le focus va au bouton, puis revient à cet élément à la sortie.
- C6. Rendu : la roue suit la taille par son `ResizeObserver` (pré-rendu regroupé, N7 tenu) ; canvas = taille CSS × `devicePixelRatio` (plafond 2400 px) à 1920 px (DPR 2) et 3840 px (DPR 1).
- C7. Non mémorisé : chaque chargement repart en mode normal (choix : un rechargement sur un projecteur ne doit pas cacher l'édition, et l'API Fullscreen exige un geste à chaque entrée).
- C8. Chat : l'outil `modeProjection` construit l'étape `modeProjection` (plus de refus `indisponible`) ; l'étage de décision le propose désormais.

## Vérification
- `src/actions.test.ts` (entrée, sortie, rotation, valeur non booléenne, essai à blanc), `src/chat/outils.test.ts` (corpus entier, outil pendant une rotation, paramètre invalide), `src/chat/decision.test.ts`.
- `tests/e2e/projection.spec.ts` (chromium, 11 tests) : entrée par le bouton, contrôles masqués, Espace puis annonce, Échap ferme l'annonce puis sort (chemin Keyboard Lock) ; sortie par le bouton et par le navigateur ; sans Keyboard Lock, sortie du navigateur annonce ouverte (simulée par `fullscreenchange`) ; promesse tenue sans plein écran ; repli CSS (API absente, refusée) ; non mémorisé ; 1920 et 3840 px ; axe-core ; édition chat « active le mode projection », et à 320 px tiroir ouvert (mesure des boîtes). `src/ui/projection.test.ts` : `poserUneFois`.
- Banc des règles, lot `dev` : `modeProjection` 0/2 avant, 2/2 après ; 96/96 au total. `src/banc/fuite.test.ts` vert. `check:size` : `roue.html` 78,5 Ko, `roue-chat.html` 150,2 Ko.
