# V1.2 — Extension des supports

Décision d'Anaël du 2026-10-31 : la V1.0 est garantie sous Windows et Chrome. Les autres supports passent en V1.2.

## À rétablir

- CI : remettre les trois OS et les trois moteurs dans `.github/workflows/ci.yml` ; `playwright.config.ts` garde déjà les trois projets.
- Navigateurs de N5 : Edge, Firefox, Safari (macOS et iOS), Chrome Android, ainsi que macOS et Linux.
- Recette sur téléphone réel : toucher, fluidité (30 images/s à 100 noms), reprise du son sur iPhone, page GitHub Pages et QR code.

## Déjà connu

- Sous WebKit, en CI Linux, la médiane par image dépasse 150 ms sans lien avec le nombre de noms : le test n'y applique pas de seuil de temps.
- Sous Safari macOS, Tab saute les boutons : le test clavier utilise Option+Tab.
- Le toucher n'est pas simulé par Playwright sous Firefox.
- Sous WebKit Windows, `AudioContext` paraît absent : le son y est sans effet.
